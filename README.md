# TANIROVKA — FULL PRO YAKUNIY

Frontend + Node.js backend + admin panel + PWA.

## Ishga tushirish
1. ZIP faylni Desktop'ga to'liq Extract qiling.
2. `START.bat` faylini bosing.
3. Sayt brauzerda avtomatik ochiladi.

3000-port band bo'lsa 3001–3020 oralig'idan bo'sh port avtomatik tanlanadi.
